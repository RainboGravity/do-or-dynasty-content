PickSix custom content

PickSix ships with a fictional league. You can play in any league you can describe: real teams, a historical season, an all-time fantasy draft, a league you invented. The world comes from a single roster file, and draft classes, faces, team marks and home fields are optional files on top of it. Share the file and you share the exact world: identical bytes produce the identical league on every machine.

Start with the Make Your Own guide. It has the two prompts to hand an assistant, the merge step, and the three rules that let any league fit the game's 32 slots.

The idea: facts, not internals

You state football facts a fan knows: a name, a team, a position, an overall rating. The game derives everything else (attribute vectors, contracts, cap math, career arcs) through the same systems it uses for its own players. You never touch internal schema. A player fact says who the player is; the game figures out what he is.

The shortest possible roster file:

{
  "formatVersion": 1,
  "players": [
    { "name": "Marcus Vale", "team": "cin", "position": "QB", "ovr": 88 }
  ]
}

Every team you don't mention keeps its shipped defaults. Every roster hole the game fills for you, and the load report tells you how many.

Loading a file

New Game → Roster → Load .json file. You'll see a validation report: errors block (fix and reload), warnings proceed (they explain what the game filled in or adjusted), info summarizes the league you're about to enter. If it's clean, start in that world and pick your franchise.
